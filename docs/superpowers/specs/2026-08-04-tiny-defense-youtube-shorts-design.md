# Tiny Defense YouTube Shorts 제작 설계

## 목표

Tiny Defense를 서로 다른 관점으로 소개하는 한국어 YouTube Shorts 3편을 제작한다. 각 완성본에 사용한 게임 장면은 자막, 전환, 엔드카드가 없는 편집용 MP4로 별도 보존한다.

## 결과물

- `01_strategy_twist.mp4`: 전략 반전형, 약 18초
- `02_combat_impact.mp4`: 전투 임팩트형, 약 16초
- `03_gameplay_explainer.mp4`: 게임 설명형, 약 20초
- `raw_clips/*.mp4`: 장면별 무자막 원본 클립
- `README.md`: 클립 설명, 사용 영상, 기술 규격

모든 영상은 세로 `1080x1920`, `30fps`, H.264 영상과 AAC 스테레오 오디오로 제공한다. 완성본과 원본 모두 게임의 BGM과 효과음만 사용하며 내레이션과 외부 음악은 사용하지 않는다.

## 캡처 방식

최신 Tiny Defense Windows 빌드와 기존의 결정적 장면 캡처 하네스를 사용한다. 고급 장면을 안정적으로 재현할 수 있고, 실제 게임 렌더링을 그대로 확보할 수 있기 때문이다.

캡처 프레임은 원본 비율을 유지한 채 nearest-neighbor 방식으로 확대한다. 원본 클립에는 홍보 자막, 로고, 컷 전환, 엔드카드를 넣지 않는다. 캡처 과정에서 오디오가 기록되지 않는 장면은 게임에 포함된 BGM과 효과음을 장면의 이벤트 타이밍에 맞춰 복원한다.

## 영상 구성

### 1. 전략 반전형

평화로운 낮과 위협적인 밤의 대비를 한 문장처럼 연결한다.

1. 낮 채집과 평온한 들판
2. 밤 전환 또는 대규모 적 등장
3. 병력과 타워의 방어전
4. 성 함락 또는 방어 결과
5. 엔드카드: `당신은 몇 번째 밤까지?`

첫 1초 안에 낮의 밝은 화면을 보여주고, 3초 안에 밤 전투로 전환한다. 자막은 화면에서 실제로 확인되는 내용만 설명한다.

### 2. 전투 임팩트형

게임의 전투 밀도와 특수 시스템을 빠르게 보여준다.

1. 대규모 적 무리
2. 병력 집결 또는 타워 교전
3. 영웅 광역 기술
4. 보스 일기토 커맨드
5. 계절 전환
6. 짧은 스토어 엔드카드

각 장면은 대체로 2~3초를 사용한다. 타격, 참격, 보스 등장, 계절 해금 효과음을 컷의 시각 이벤트와 맞춘다.

### 3. 게임 설명형

`낮의 준비가 밤의 생존을 결정한다`는 플레이 루프를 이해시키는 데 집중한다.

1. 자원 채집
2. 도구 또는 성장 선택
3. 병력 배치와 타워 구성
4. 자동 전투
5. 유물 선택
6. 계속되는 밤과 생존 목표
7. 스토어 엔드카드

자막은 `낮엔 모으고`, `부대를 키우고`, `밤엔 지킨다`처럼 짧은 동사형 문장으로 구성한다.

## 편집 원칙

- 화면이 증명하지 못하는 홍보 문구를 쓰지 않는다.
- 세로 게임 화면을 크롭하지 않고 전체 높이를 유지한다.
- 픽셀 아트 확대에는 이웃 보간을 사용해 경계를 흐리지 않는다.
- 자막은 플랫폼 UI 안전 영역 안에 두고 한 화면 두 줄을 넘기지 않는다.
- 각 완성본 끝에 약 1.5초의 Tiny Defense 스토어 CTA를 둔다.
- 컷 사이의 음량 차이를 제한하고 최종 출력에서 피크 클리핑과 사실상 무음을 검사한다.

## 검수 기준

- 모든 MP4가 `1080x1920`, `30fps`, H.264/AAC로 재생된다.
- 원본 클립에 홍보 자막, 엔드카드, 편집 전환이 없다.
- 완성본 3편이 서로 다른 메시지와 장면 흐름을 가진다.
- 자막이 잘리거나 게임 UI와 겹치지 않는다.
- 오디오가 존재하며 컷 경계에서 갑작스러운 무음이나 클리핑이 없다.
- 각 완성본의 대표 프레임과 시작, 중간, 끝 프레임을 육안으로 확인한다.
- 출력 파일과 원본 클립의 목록, 길이, 사용처가 `README.md`와 일치한다.
