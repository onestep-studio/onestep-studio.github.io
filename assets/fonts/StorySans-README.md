# Story Sans

Storybook-only variable font, subset from Pretendard JP 1.3.9 for the site's
Korean, English, and Japanese story and controls. Loaded when the reader opens.

Source: https://github.com/orioncactus/pretendard/tree/v1.3.9
Original file: `packages/pretendard-jp/dist/web/variable/woff2/PretendardJPVariable.woff2`.
Copyright (c) 2021, Kil Hyung-jin. SIL Open Font License 1.1, included in
`Pretendard-OFL.txt`. The derivative is renamed to respect the reserved font name.

Rebuild with `tools/build-story-font.py` (fonttools and brotli), using the original
file in `output/fonts/PretendardJPVariable-v1.3.9.woff2`. Rebuild after adding story
characters; system font fallbacks cover characters outside the subset.
